Sawaal Saathi Sawaal Saathi is a friendly interview-practice agent for students, learners, and job seekers. It asks interview questions, scores answers using the Situation–Task–Action–Result structure, and provides clear coaching for the next attempt. ## What it does Sawaal Saathi helps users practise interview answers without needing another person to conduct a mock interview. The application provides: - Interview questions - A score out of 100 - Situation, Task, Action, and Result checks - Friendly coaching feedback - A practical next step for improvement ## AWS services - AWS Lambda - AWS Lambda Function URL - AWS IAM - Amazon CloudWatch - Amazon Bedrock integration path ## Deployment The Python application is packaged as a ZIP file and deployed to AWS Lambda. The Lambda Function URL provides the public web endpoint. ## Live demo https://hzq2lm4m3twfz3qn5ezibanmpq0gpjbe.lambda-url.us-east-1.on.aws/ ## Current status The deployed application successfully loads questions, scores answers, and provides structured coaching. The current deployment uses an offline simulator while Amazon Bedrock/Nova Lite access is pending. ## Verification The deployment verification passed checks for: - Web page loading - Question endpoint - Scorecard functionality
